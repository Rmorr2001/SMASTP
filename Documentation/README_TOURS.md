# Tour Viewer for SMASTP

This tool allows you to view and explore the tours generated by the Stochastic Multi-Activity Tour Scheduling Problem (SMASTP) model.

## Features

- List all generated tours with summary information
- View detailed information for specific tours
- Generate new tours with customizable parameters
- Save tour information to CSV files
- Visualize tour schedules

## Usage

### Basic Usage

To view a list of available tours:

```bash
python view_tours.py --list
```

To view detailed information for a specific tour:

```bash
python view_tours.py --view 1
```

### Advanced Options

- `--model PATH`: Load a model from a pickle file
- `--save PATH`: Save the model to a pickle file
- `--list`: List all tours
- `--view ID`: View details for a specific tour ID
- `--num N`: Number of tours to display (default: 10)
- `--detailed`: Show detailed information for each tour
- `--output DIR`: Directory to save tour information as CSV
- `--generate`: Generate new tours
- `--max-tours N`: Maximum number of tours to generate (default: 1000)

### Examples

Generate new tours and list them:

```bash
python view_tours.py --generate --list
```

View detailed information for the first 20 tours and save to CSV:

```bash
python view_tours.py --list --num 20 --detailed --output results
```

Load a model, view a specific tour, and save the model:

```bash
python view_tours.py --model results/model.pkl --view 5 --save results/updated_model.pkl
```

## Tour Information

Each tour represents a weekly schedule for an employee and includes:

- Working days (which days of the week)
- Total working hours
- Number and types of shifts (8-hour, 6-hour, 4-hour)
- Detailed schedule with start and end times for each shift

## Visualization

When viewing a specific tour with `--view`, a visualization of the tour schedule will be displayed, showing:

- Shifts across the week
- Different colors for different shift types
- Start and end times for each shift

## Integration with SMASTP

This tool integrates with the main SMASTP model and can be used to:

1. Explore the tours generated by the model
2. Understand the structure of optimal tour assignments
3. Analyze the diversity of generated tours
4. Export tour information for further analysis
